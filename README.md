# A-Mashiro Arabic Site (Prototype)

## 管理画面（ドラッグ&ドロップでアップロード・削除・並び替え）

`admin.html` にアクセスすると、ブラウザ上から直接:
- 画像をドラッグ&ドロップで追加
- カードの✕ボタンで削除
- カードをドラッグして並び替え

ができます。トップページのスライドショー、ABOUTの写真、すべての作品ページが対象です。
保存すると GitHub のリポジトリに直接コミットされ、1〜2分程度でサイトに反映されます。
サーバー費用は一切かかりません（GitHubの無料機能のみ使用）。

### 初回セットアップ（GitHubの個人アクセストークンを作る）
1. GitHubにログインし、右上のアイコン → Settings → 左メニュー下部の
   "Developer settings" → "Personal access tokens" → "Fine-grained tokens" を開く
2. "Generate new token" を押す
3. Repository access を「Only select repositories」にし、このサイトのリポジトリだけを選択
4. Permissions の "Contents" を **Read and write** に設定（他はそのままでOK）
5. 発行されたトークン（`github_pat_...` や `ghp_...` から始まる文字列）をコピー
6. `admin.html` を開き、「設定」から
   - owner: GitHubのユーザー名
   - repository: リポジトリ名
   - branch: 通常は `main`
   - Personal Access Token: 5でコピーした文字列
   を入力して保存

このトークンはブラウザ内（localStorage）にのみ保存され、他には送信されません。
ただし**サイトへの書き込み権限を持つ機密情報**なので、他人と共有しないでください。
`admin.html` はサイトのナビゲーションからはリンクしていません（URLを知っている人だけがアクセスできます）。

### 使い方
1. 左のメニューから編集したい項目を選ぶ（例: 「عدم الاصطفاف」）
2. 画像をドロップ、またはクリックしてファイル選択
3. 必要ならタイトルを入力、カードをドラッグして順番を調整
4. 不要な画像は✕で削除
5. 「حفظ ونشر（保存して公開）」を押す

## 作品を追加する方法（HTMLの編集は不要・上級者向け手動編集の場合）


各シリーズには `images/<シリーズ名>/` フォルダと `data/<シリーズ名>.json` が対応しています。
例: Misalignment シリーズ → `images/misalignment/` フォルダ + `data/misalignment.json`

### 手順
1. 追加したい画像を `images/<シリーズ名>/` フォルダに置く（例: `02.jpg`）
2. 対応する `data/<シリーズ名>.json` を開き、配列に1行追加する

```json
[
  { "file": "01.jpg", "title": "عدم الاصطفاف" },
  { "file": "02.jpg", "title": "عدم الاصطفاف" }
]
```

- `file`: images フォルダ内のファイル名のみでOK（パス不要）
- `title`: マウスオーバー時・拡大表示時に出るタイトル（省略可）

保存すればページを開いたときに自動でギャラリーに反映されます。HTMLファイルは一切触りません。

## 注意点（ローカルで確認する場合）
このギャラリーは画像リストを `fetch()` で読み込む仕組みのため、
`index.html` をブラウザで直接ダブルクリックして開くと、ブラウザのセキュリティ制限で
画像が表示されないことがあります。ローカルで確認したい場合は、フォルダ内で以下を実行してください。

```
python3 -m http.server 8000
```

その後ブラウザで `http://localhost:8000/` を開くと正しく確認できます。
（GitHub Pagesなど、実際にサーバー経由で公開した後は問題なく動作します。）

## ホスティング
1. このフォルダの中身を GitHub の新規リポジトリ（例: a-mashiro-ar）にそのままアップロード
2. リポジトリの Settings > Pages で「Deploy from branch」→ main / (root) を選択
3. 数分で https://ユーザー名.github.io/a-mashiro-ar/ で公開されます（無料）
4. 独自ドメインを使う場合は、ドメインのDNSにCNAMEレコードを設定し、リポジトリ直下に `CNAME` ファイル（中身はドメイン名のみ）を追加

## 画像について
現在 images/ 内にある画像は、いただいたスクリーンショットからの仮トリミングです。
本番公開時は元の高解像度データに差し替えることを推奨します。
